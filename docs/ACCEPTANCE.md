- 参数按原样传给子进程，中文、空格、shell 特殊字符不会被执行；保留非零退出码。
- 取消终止子进程；可执行文件缺失正确报错。
- 解析部分成功与不完整事件；40,000 字符警告不被界面日志上限截断。
- 队列输入校验、去重、重试与移除；导出拒绝覆盖输入及其符号链接。
- macOS Foundation 启动的 Python 进程正确进入事件协议。
- 实际 Docling 子进程取消后队列标记为已取消，运行状态释放；手动重试成功，并加载真实中英文预览。
- 中文 HTML 标题、段落、列表、表格与三种导出；含空格的文件路径。
- 损坏 Office 文件报错；已有结果目录拒绝覆盖；URL 输入拒绝。

## 0.2 批量与生命周期回归

- 1,000 文件目录在后台扫描；重复导入不增加条目，文件修改后可以再次加入。
- 100 HTML / 20 种内容的真实 Docling 批次：第一批命中 80 份，第二批命中 100 份；缓存全命中不初始化转换器。
- 文件内容、OCR、模型身份、引擎锁与工作代码变化均使旧缓存失效；缺结果或缺 manifest 时重建；失败及部分成功不进入缓存。
- 缓存容量和过期清理保留当前引用结果；另一转换进程被缓存锁拒绝，避免双份模型争抢资源。
- 实时 stdout 事件不等待管道填满；取消清理忽略 TERM 的后代，也覆盖父进程已退出的场景。
- 批量导出同名及大小写冲突自动编号；512 KiB 预览边界不截断实际导出。
- 真实 Docling 生成的 4 MiB JSON，经复用导出后来源文件名正确，中文、引号、64 位无符号哈希不丢失，正文逐字节一致且共享缓存未修改。
- 未知 JSON 结构不覆盖已有导出；512 MiB 大文件复制进行中取消，临时文件被清理、已有目标内容保留。
- 真实 uv 修复失败时，移除旧环境就绪标记；重新启动也不会误报可用。该回归使用隔离环境，不修改实际安装环境。

## 真实跨窗口鼠标拖拽（0.2.1）

用户授权使用 macOS CGEvent，实际从 Finder 多选测试文件及文件夹，按下鼠标、连续移动并在客户端释放；没有用文件选择器、URL 打开或直接调用队列方法代替。

首次复现出 0.2.0 的问题：空窗口可以接收，HTML 预览区则由 WebKit 吞掉拖放，底栏仍正常。0.2.1 增加专用 WKWebView 拖放处理，将本地文件 URL 转交原有导入队列，保留预览与导航限制。

修复后实际回归：

1. 将一个 HTML 和两个子文件夹同时拖到空窗口，读取三个 HTML 文件，队列为 3。
2. 转换完成并显示 HTML 预览后，将同一批再次拖到预览区，显示「已添加 0 份，跳过 3 份未改变的文件」，队列仍为 3。
3. 在 Finder 批次中加入 `追加.md`，将四项再次拖到预览区，显示新增 1 份、跳过 3 份，队列为 4；原有预览未被导航替换。
4. 转换追加文件，全部四份完成，三份复用缓存，批次结束释放模型。

最终窗口见 [drag-drop.png](drag-drop.png)。三组 NSPasteboard 自动检查将文件 URL 接收规则纳入 CI。后续交互优化扩大到整个内容区，加入常驻虚线提示和拖入时的整窗覆盖提示；真实鼠标在右侧内容区边缘悬停时的截图见 [drop-hover.png](drop-hover.png)。

## 自动队列和短时提示

新版原生窗口已实际验证自动转换，重新添加的记录移到顶部并选中，提示消退后恢复「已完成」。新增真实引擎回归已验证：导入即自动转换；不同文件的相同内容复用结果；重新添加相同文件时不新增行、移到顶部并选中；4 秒后复用提示消失，记录保持已完成。提示共用一个睡眠任务，到期后没有常驻轮询。

真实运行中停止后，队列进入暂停状态；此时新增文件保持等待，手动继续后转换；重试取消的文件会自动开始。右上角普通开始按钮已移除，仅运行时显示停止、暂停且有等待项时显示继续。
